# ROSA — Reformed Orthodoxy Study Assistant

改革宗正统研习助手。帮助你自己读懂圣经，也参与神学研究、默想、思辨与创作。

**[下载 v1.9.25 r14 · 有限保证版](https://github.com/subverse-rosa/rosa-skill/releases/tag/skill-v1.9.25-r14-limited)** · [安装指南](INSTALL.md) · [发行限制](LIMITED-RELEASE-NOTES.md) · [更新记录](CHANGELOG.md) · [使用与贡献条款 / Terms](LICENSE.md)

七个模块可单独使用，也可在自然对话中搭配：查经导师、神学研究、灵修助手、第三空间、神学健身房、讲章架构师、礼仪编排。编辑审稿台、辅助素材库与个人思考工具箱组成创作工具台，参与不同任务。

## 本版整合

- 讲章架构师：点数服从经文；从经文到基督的关联分八种方式，每处写出方式与根据，称预表须先是原处境的象征。
- 引用与来源：推荐注释书或讲道者时也附来源；没读到的标“未读”，只作线索。
- 在 Gemini 技能库附加的 NotebookLM 会被按题目查询。
- 新增 `/feedback` 反馈报告，以及 NotebookLM 方法挖掘命令 `/mine-map`、`/mine-deep`、`/mine-test` 与 ROSA 的 `/mine-merge`。
- 个人思考工具箱新增磨利与合并规则。

本版是有限保证使用版，**不是完整独立验收 PASS**。关键经文、引语、作者归属、版本与定位须依实际来源核对。最后完整独立验收基线为 [v1.9.20](https://github.com/subverse-rosa/rosa-skill/releases/tag/skill-v1.9.20)。

## 开始使用

1. 下载 Release 附件 `rosa-skill-v1.9.25-r14-package.zip`，同时阅读发行限制。
2. 按安装指南导入完整 `rosa/`；升级前备份个人 `references/user_toolbox.md`，替换安装后放回，并重新附加 NotebookLM。
3. 新开对话核对 v1.9.25 r14，从当前任务开始，不必先选择模式。

> 请使用 ROSA。以下是我提供的经文文本：〔贴入经文及译本〕。先提出两个观察问题，暂时不要生成完整教案；需要外部资料时，区分已读来源与尚未核实的内容。

GitHub 自动生成的 Source code ZIP / TAR 不是安装包。包内 candidate／PENDING 为打包时历史标记，有限采用由发行说明记录；不为更换标记重打包。
