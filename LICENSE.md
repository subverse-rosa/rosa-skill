# ROSA 使用与贡献条款

**使用与分享**

个人和教会可从官方发布页下载 ROSA 安装包，免费安装、使用和在本地修改，供个人或教会内部使用。欢迎分享官方发布链接。重新分发安装包或发布修改版，须事先取得 ROSA 权利人的许可。

**贡献**

向 ROSA 提交 Pull Request 时，你确认自己有权授权该贡献，并授予 ROSA 维护者非独占、免版税的许可，以合入、修改、维护该贡献，并随 ROSA 官方版本发布。

**适用范围**

本条款适用于 ROSA 权利人有权许可的官方安装包内容。第三方材料适用各自的条款。中英文如有歧义，以中文为准。
